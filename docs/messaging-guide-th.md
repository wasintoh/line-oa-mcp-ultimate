# คู่มือ LINE Messaging (37 tools) ภาษาไทย

> สั่งงาน LINE Official Account ด้วย "ภาษาคน" ผ่าน AI — ส่ง broadcast, ออกแบบ Flex, สร้าง rich menu, ทำ audience, ดู insight, จัดการคูปอง โดยไม่ต้องเปิดหน้าเว็บ LINE OA Manager หรือเขียนโค้ดเลย

คู่มือนี้สำหรับ **marketer / เจ้าของร้าน / แอดมินเพจ / agency** ที่ใช้ LINE OA และอยากให้ AI ช่วยทำงาน อ่านจบแล้วจะเข้าใจเครื่องมือฝั่งข้อความครบทั้ง 34 ตัว ว่าแต่ละตัวทำอะไร พูดยังไงให้ AI ทำให้ และมีอะไรต้องระวัง

> 🛍️ ถ้าใช้ **LINE Shopping (จัดการสินค้า/ออเดอร์)** ด้วย ดูคู่มือคู่กัน: [`myshop-guide-th.md`](myshop-guide-th.md)
> 🚀 ถ้ายังไม่เคยตั้งค่า MCP เลย เริ่มที่ [`quickstart-th.md`](quickstart-th.md) ก่อน

## 1. เข้าใจพื้นฐานก่อน 3 เรื่อง

### เรื่องที่ 1 — "ส่งหาใคร" มี 5 ช่องทาง (transports)

| ช่องทาง | ส่งหาใคร | ค่าใช้จ่าย | หมายเหตุ |
|---|---|---|---|
| **reply** | ตอบกลับ 1 คนที่เพิ่งทักมา | ฟรี | ใช้ได้ภายใน ~25 วินาทีหลังลูกค้าทัก (หลังจากนั้นหมดอายุ ระบบจะ fallback ไป push ให้) |
| **push** | ส่งหา 1 คน (รู้ user id) | คิด quota | — |
| **multicast** | ส่งหาหลายคน | คิด quota | ครั้งละ ≤500 คน เกินนั้นระบบแบ่งให้เอง |
| **narrowcast** | ส่งตาม audience หรือเงื่อนไข (เพศ/อายุ/พื้นที่) | คิด quota | ต้องมีกลุ่มเป้าหมาย **≥50 คน** ไม่งั้น LINE ปฏิเสธ |
| **broadcast** | ส่งหาเพื่อนทุกคน | คิด quota | ต้อง **ยืนยัน (confirm)** เสมอ เพราะกระทบทุกคน |

### เรื่องที่ 2 — "ส่งจริง / ซ้อม / ร่าง" มี 3 โหมด

- **`send_now`** — ส่งจริงทันที (ผ่านระบบเช็ก quota + quiet hours)
- **`dry_run`** — "ซ้อมส่ง" ตรวจว่าข้อความถูกไหม + บอกว่าจะส่งกี่คน เปลือง quota เท่าไหร่ **แต่ยังไม่ส่งจริง** (แนะนำทำก่อน broadcast ใหญ่ทุกครั้ง)
- **`draft`** — เตรียมแบบร่าง แล้วเอาไปตั้งเวลาส่งในหน้า LINE OA Manager (LINE delivery เสถียรกว่า + มี audit log)

### เรื่องที่ 3 — ระบบกันพลาด (Safety Model)

ทุกครั้งที่จะ "ส่ง" หรือ "เปลือง quota" ระบบจะวิ่งผ่านด่านเหล่านี้อัตโนมัติ:

```
ตรวจรูปแบบข้อความ (validate กับ LINE ก่อน เพื่อไม่ให้เสีย quota ฟรีๆ)
   ↓
Quota Guardian — ถ้าจะใช้เกิน 95% ของ quota ที่เหลือ → บล็อก จนกว่าจะสั่ง confirm
   ↓
Quiet Hours — ถ้าเป็นช่วง 22:00–08:00 (เวลาไทย) → เตือน จนกว่าจะสั่ง force
   ↓
ส่งจริง แล้วตอบกลับเป็นภาษาไทยที่เข้าใจง่าย
```

> เครื่องมือที่ "อ่านอย่างเดียว" (เช่น ดูสถานะ ดู insight) ไม่ต้องผ่านด่านพวกนี้ — ปลอดภัย เรียกได้สบาย

## 3. คู่มือทีละเครื่องมือ

แต่ละตัวมี: **ทำอะไร** · **พูดแบบนี้** · **ข้อควรระวัง**

### 📨 กลุ่มส่งข้อความ

#### `line_send_message` — ส่งข้อความ (ตัวหลักของทั้งระบบ)
เครื่องมือเดียวครอบทุกช่องทาง (reply/push/multicast/narrowcast/broadcast) และทุกรูปแบบข้อความ: ข้อความ (≤5,000 ตัว), Flex (เทมเพลตหรือ JSON), สติกเกอร์, รูป, วิดีโอ (mp4), คูปอง LINE, และ message สำเร็จรูปจากเครื่องมือออกแบบ

- 🗣️ "ส่งข้อความขอบคุณไปให้ลูกค้าคนนี้" · "ซ้อมส่งโปรวันแม่ให้ผู้หญิง 25-44 ดูก่อนว่ากี่คน" · "เตรียมร่าง broadcast ไว้ตั้งเวลาใน OA Manager"
- ⚠️ broadcast (`everyone`) ต้อง **confirm** เสมอ · ส่งช่วง 22:00–08:00 ต้อง **force** · narrowcast ต้องกลุ่ม ≥50 คน · ก่อนยิงใหญ่ "ซ้อมด้วย dry_run" ทุกครั้ง

#### `line_find_sticker` — ค้นสติกเกอร์ตามอารมณ์
ค้นสติกเกอร์ LINE ด้วยคำอารมณ์ไทย/อังกฤษ (ขอบคุณ, ดีใจ, ขอโทษ, celebration)

- 🗣️ "หาสติกเกอร์ขอบคุณ" · "ขอสติกเกอร์ดีใจหน่อย"
- 💡 ใช้คู่กัน: ค้น → เลือกตัวที่ชอบ → สั่งส่งด้วย `line_send_message`

### 🎨 กลุ่ม Rich Menu

#### `line_build_rich_menu` — สร้างเมนูปุ่มจบในคำสั่งเดียว
รวมทุกขั้นในครั้งเดียว: ตรวจรูป → สร้างเมนู → อัปโหลดรูป → ตั้งเป็นเมนูหลัก ระบุพื้นที่กดแต่ละปุ่ม (เปิดลิงก์/ส่งข้อความ/postback/สลับแท็บ)

- 🗣️ "สร้าง rich menu โปรเดือนนี้ ปุ่ม 'ดูสินค้า' 'โปรโมชัน' 'ติดต่อ' ตั้งเป็นเมนูหลัก"
- ⚠️ รูปต้อง **HTTPS ตรง** JPEG/PNG ≤1 MB สัดส่วน ≥1.45 · OA เก็บได้สูงสุด 1,000 เมนู (เช็กด้วย `list_rich_menus` ก่อน)

#### `line_list_rich_menus` — ดูเมนูทั้งหมด
แสดงเมนูทุกตัวบน OA + บอกว่าตัวไหนเป็นเมนูหลัก (อ่านอย่างเดียว)
- 🗣️ "ดูเมนูปุ่มทั้งหมด"

#### `line_delete_rich_menu` — ลบเมนู
- 🗣️ "ลบ rich menu ตัวนี้ ยืนยัน"
- ⚠️ ลบแล้วเอากลับไม่ได้ ต้อง **confirm** · แนะนำเช็ก `audit_user_menu` ก่อนว่าไม่มีใครผูกอยู่

#### `line_audit_user_menu` — เช็กเมนูของผู้ใช้
ตอบคำถาม "ทำไมลูกค้าคนนี้ไม่เห็นเมนู?" — ดูว่าผู้ใช้เห็นเมนูไหน (เมนูผูกรายคน > เมนูหลัก > ไม่มี)
- 🗣️ "เช็กว่า user คนนี้เห็นเมนูไหน"

#### `line_link_rich_menu` — ผูก/ถอดเมนูกับผู้ใช้
ผูกเมนูเฉพาะกับผู้ใช้คนเดียวหรือหลายคน (เกิน 500 คนระบบแบ่งให้เอง) เมนูผูกรายคนจะ override เมนูหลัก
- 🗣️ "ผูกเมนู VIP ให้ลูกค้ากลุ่มนี้" · "ถอดเมนูของ user คนนี้"

#### `line_set_default_rich_menu` — ตั้ง/ลบเมนูหลัก
ตั้งเมนูหลักของ OA (คนที่ไม่ถูกผูกรายคนจะเห็นตัวนี้)
- 🗣️ "ตั้งเมนูหน้าร้อนเป็นเมนูหลัก" · "ลบเมนูหลักออก"

#### `line_manage_rich_menu_alias` — จัดการ alias (เมนูสลับแท็บ)
สร้าง/แก้/ลบ alias สำหรับเมนูแบบสลับแท็บ — เปลี่ยนปลายทาง alias ได้ทันทีโดยไม่ต้องไปผูกผู้ใช้ใหม่
- 🗣️ "สร้าง alias แท็บโปร ชี้ไปเมนูนี้" · "เปลี่ยน alias แท็บโปร ไปชี้เมนูเซลแทน"

#### `line_upload_rich_menu_image` — เปลี่ยนรูปเมนูเดิม
เปลี่ยนแค่รูป โดยพื้นที่ปุ่มและการผูกผู้ใช้ยังอยู่เหมือนเดิม
- 🗣️ "เปลี่ยนรูปเมนูนี้เป็นโปรแกรมหน้าร้อน"
- ⚠️ รูปต้อง HTTPS JPEG/PNG ≤1 MB

### 💎 กลุ่มออกแบบข้อความ

#### `line_design_flex` — ออกแบบ Flex Message
สร้าง Flex จาก **8 เทมเพลตไทย** (เช่น คูปอง, โปรโมชัน, ใบเสร็จ) หรือ JSON เอง — ได้ลิงก์ preview กลับมาดูก่อนส่ง
- 🗣️ "ออกแบบ Flex คูปองลด 50% ถึง 31 มี.ค." · "ขอดูเทมเพลตที่มีทั้งหมด"
- ⚠️ Flex 1 bubble ≤30 KB · carousel ≤12 bubble · ผลที่ได้เอาไปส่งต่อด้วย `send_message`

#### `line_design_imagemap` — ออกแบบ Rich Message
รูปใหญ่ที่กดได้หลายจุด + ใส่วิดีโอเล่นในรูปได้
- 🗣️ "ทำ Rich Message รูปร้าน แบ่ง 3 จุดกด: เมนู / โปร / แผนที่"
- ⚠️ ความกว้างมาตรฐาน 1040px · **v2.2: ไม่ต้อง host เองแล้ว** — เรียก `line_prepare_image` ก่อน แล้วส่ง `prepared_key` มาแทน `base_url`

#### `line_design_card` — ออกแบบ Card Message
การ์ดสำเร็จรูป 4 แบบ: ปุ่ม (buttons), ยืนยัน (confirm), การ์ดเลื่อน (carousel), การ์ดรูปเลื่อน (image_carousel)
- 🗣️ "ทำการ์ดปุ่ม: สั่งซื้อ / ดูรายละเอียด / ทักแชท"
- ⚠️ buttons ≤4 ปุ่ม · carousel ทุกการ์ดต้องมีจำนวนปุ่มเท่ากัน (กฎ LINE) · สูงสุด 10 การ์ด

#### `line_prepare_image` — เตรียมรูปให้พร้อมส่ง (v2.2)
แนบรูปอะไรมาก็ได้ (ไฟล์ในเครื่อง / ลิงก์) ระบบย่อครบ 5 ขนาดที่ LINE ต้องการ เปิดที่ host ให้เองอัตโนมัติ และตรวจว่า LINE ดึงได้จริงทุกขนาดก่อนบอกว่าสำเร็จ — ได้ `prepared_key` ไปใช้กับ `design_imagemap` / `send_message` ต่อทันที
- 🗣️ "ส่งรูปนี้เป็น Rich Message หาลูกค้าทุกคน"
- ⚠️ LINE มาดึงรูปตอนลูกค้า "เปิดอ่านครั้งแรก" — เปิดเครื่องทิ้งไว้จนลูกค้าส่วนใหญ่เปิดอ่าน (ระบบเปิดให้ 24 ชม.) · คู่มือเต็ม: [image-hosting-th.md](image-hosting-th.md)

#### `line_image_host_status` — เช็กสถานะระบบ host รูป (v2.2)
บอกว่าช่องทาง host ไหนพร้อมใช้ สะพานเปิดอยู่ไหม มีรูปพักในหน่วยความจำเท่าไร — อ่านอย่างเดียว เรียกได้เสมอ
- 🗣️ "ทำไม host รูปอัตโนมัติไม่ได้" · "เช็กระบบรูปหน่อย"

### 🎯 กลุ่ม Audience

#### `line_build_audience_from_csv` — สร้างกลุ่มจากรายชื่อ
สร้างกลุ่มเป้าหมายจากรายการ user id (เช่นจาก CSV ลูกค้า) ครั้งละ ≤10,000 คน
- 🗣️ "สร้าง audience ลูกค้าที่ซื้อเดือนก่อน จากรายชื่อนี้"
- ⚠️ สร้างเสร็จต้อง **รอ ~10 นาที** (สถานะ IN_PROGRESS) ก่อนใช้ส่งได้ · ต้อง ≥50 คนถึงจะ narrowcast ได้

#### `line_build_audience_from_engagement` — สร้างกลุ่มจากคนที่มีปฏิสัมพันธ์ (retargeting)
สร้างกลุ่มอัตโนมัติจากคนที่ "คลิก" หรือ "เปิด" ข้อความที่ส่งไปแล้ว
- 🗣️ "สร้าง audience จากคนที่คลิกโปรที่ส่งไปเมื่อวาน"
- ⚠️ ต้องรอ **≥24 ชม.** หลังส่งข้อมูลถึงนิ่ง · ใช้ได้เฉพาะ TH/JP/TW + premium

#### `line_list_audiences` — ดูกลุ่มทั้งหมด
ดู audience ทุกกลุ่ม + สถานะ (READY ใช้ได้ / IN_PROGRESS รออยู่ / FAILED-EXPIRED ต้องสร้างใหม่)
- 🗣️ "ดู audience ทั้งหมด" · "ดูเฉพาะกลุ่มที่พร้อมใช้ (READY)"

#### `line_delete_audience` — ลบกลุ่ม
- 🗣️ "ลบ audience นี้ ยืนยัน" · ⚠️ ลบแล้วเอากลับไม่ได้ ต้อง **confirm**

#### `line_update_audience` — เพิ่มคน/เปลี่ยนชื่อ
- 🗣️ "เพิ่มลูกค้า 3 คนเข้า audience นี้" · "เปลี่ยนชื่อ audience เป็น 'VIP มิ.ย.'"
- ⚠️ ได้เฉพาะ audience ที่สร้างด้วย API (กลุ่มที่ติด tag จากหน้า OA Manager แก้ไม่ได้)

### 📊 กลุ่ม Insight

#### `line_get_oa_status` — เช็กสุขภาพ OA
สรุปด่วน: จำนวนเพื่อน, quota ที่เหลือ (%), webhook ทำงานไหม, เมนูหลักคือตัวไหน
- 🗣️ "ดูสถานะ OA หน่อย"

#### `line_get_oa_report` — รายงานสรุปหลายวัน
รายงาน delivery + followers + demographic + quota เลือกช่วงเวลาได้ (สัปดาห์ที่แล้ว / เดือนนี้ / กำหนดเอง)
- 🗣️ "สรุปผลสัปดาห์ที่แล้ว" · "รายงาน 1–15 มิ.ย."
- ⚠️ ข้อมูล insight ดีเลย์ ~2 วัน (T-2) · ถ้ากลุ่ม < 20 คน LINE คืนค่าว่าง (เพื่อความเป็นส่วนตัว)

#### `line_get_message_stats` — สถิติข้อความที่ส่ง
ดู impression / เปิด / คลิก / CTR ของข้อความที่ส่งไป (narrowcast/multicast/broadcast)
- 🗣️ "broadcast เมื่อวานมีคนคลิกกี่คน"
- ⚠️ ข้อมูลดีเลย์ ~24 ชม. (T-1) · ใช้ได้เฉพาะข้อความที่ส่งหลายคน (ส่งคนเดียวไม่มีสถิติ)

#### `line_estimate_send_cost` — ประมาณ quota ก่อนส่ง
บอกคร่าวๆ ว่าจะใช้ quota กี่ข้อความ โดยไม่ส่งจริง
- 🗣️ "ถ้าส่ง 2 ข้อความให้ audience VIP จะเปลือง quota เท่าไหร่"
- 💡 ถ้าปลายทางเป็น filter/ทุกคน (จำนวนไม่แน่นอน) ใช้ `send_message` แบบ dry_run จะแม่นกว่า

#### `line_get_narrowcast_progress` — เช็กความคืบหน้า narrowcast
narrowcast ส่งแบบ async — ตัวนี้บอกว่าส่งไปถึงไหนแล้ว (รอ/กำลังส่ง/เสร็จ/ล้มเหลว)
- 🗣️ "narrowcast ที่เพิ่งยิงไป ส่งเสร็จยัง"

### 🎟 กลุ่มคูปอง

#### `line_manage_coupon` — จัดการคูปอง
สร้าง/ดู/ปิด คูปอง LINE — ตั้งเปอร์เซ็นต์/จำนวนเงิน, ช่วงเวลา, จำกัดจำนวน, แบบสุ่ม (lottery) ได้
- 🗣️ "สร้างคูปองลด 20% ใช้ได้ 1–8 มิ.ย." · "ดูคูปองทั้งหมด" · "ปิดคูปองนี้ ยืนยัน"
- ⚠️ ปิดคูปอง (discontinue) ต้อง **confirm** · สร้างเสร็จเอาไป broadcast เป็นคูปองในแชทด้วย `send_message` ได้

#### `line_get_coupon_stats` — สถิติคูปอง
ดูข้อมูลการใช้คูปอง — เสริมด้วย click audience เพื่อประมาณการ redemption
- 🗣️ "ดูสถิติคูปองนี้"
- ⚠️ LINE ไม่มี API นับ redemption ตรงๆ ตัวเลขเป็นการ **ประมาณ** จาก click audience

### 🔌 กลุ่ม Webhook

#### `line_test_webhook` — ทดสอบ webhook
ตอบคำถาม "ทำไมบอทไม่ตอบ?" — ให้ LINE ยิงทดสอบ webhook แล้วดูผล (status + signature)
- 🗣️ "ทดสอบ webhook" · "ทดสอบ webhook URL ใหม่นี้"

#### `line_set_webhook_endpoint` — ตั้ง/ดู URL webhook
- 🗣️ "ตั้ง webhook เป็น https://api.shop.example.com/line" · "ดู webhook ปัจจุบัน"
- ⚠️ ต้องเป็น **HTTPS** เท่านั้น

### 👤 กลุ่ม Operations & Multi-OA

#### `line_get_user_profile` — ดูโปรไฟล์ผู้ใช้
ดูชื่อ/รูป/สเตตัส/ภาษา ของผู้ใช้
- 🗣️ "ดูข้อมูล user คนนี้"
- ⚠️ ผู้ใช้ต้องเป็นเพื่อนกับ OA และไม่บล็อก ไม่งั้นได้ 404

#### `line_list_followers` — ดึงรายชื่อผู้ติดตาม
ดึง user id ของผู้ติดตามทั้งหมด (ทีละหน้า)
- 🗣️ "ดึงรายชื่อ followers"
- ⚠️ ใช้ได้เฉพาะ TH/JP/TW + premium · ร้านใหญ่ (เพื่อนหลักหมื่น) แนะนำใช้ engagement audience แทน

#### `line_list_oas` — ดู OA ที่ตั้งค่าไว้
สำหรับ agency — ดู OA ทั้งหมดในระบบ + ตัวที่ใช้งานอยู่ตอนนี้
- 🗣️ "ดู OA ทั้งหมด"

#### `line_use_oa` — สลับ OA ที่ใช้งาน
- 🗣️ "สลับไปใช้ OA ของลูกค้า A"
- 💡 หรือสั่งงานทุกเครื่องมือแบบใส่ `oa` ระบุรายครั้งก็ได้

#### `line_run_on_many_oas` — รันคำสั่งข้ามหลาย OA
รันเครื่องมือ **อ่านอย่างเดียว** พร้อมกันหลาย OA (พลังของ agency) เช่น เช็กสถานะทุกร้านรวด
- 🗣️ "เช็กสถานะทุก OA" · "ทดสอบ webhook ของลูกค้า A กับ B"
- ⚠️ รองรับเฉพาะเครื่องมืออ่านข้อมูล (status/report/list/test) — เครื่องมือที่ส่ง/แก้ ทำข้ามไม่ได้ เพื่อความปลอดภัย

### 💻 กลุ่ม LIFF & Token

#### `line_manage_liff_app` — จัดการแอป LIFF
สร้าง/ดู/แก้/ลบ LIFF app (เว็บแอปในกรอบ LINE)
- 🗣️ "สร้าง LIFF แบบ tall ชี้ไป https://myapp.example.com" · "ดู LIFF ทั้งหมด"
- ⚠️ ลบต้อง **confirm**

#### `line_check_token` — เช็ก token
เช็กว่า Channel Access Token ยังใช้ได้ไหม เหลืออายุกี่วัน
- 🗣️ "token ยังใช้ได้อยู่ไหม"
- 💡 เตือนล่วงหน้าถ้าเหลือ < 7 วัน

## 4. Workflow จริง

### A) ส่งโปรโมชันแบบมือโปร (ซ้อมก่อนยิงจริง)

```
1. "ออกแบบ Flex โปรวันแม่ ปุ่ม 'ดูสินค้า'"           → line_design_flex (ได้ preview)
2. "เช็ก audience 'mothers-day-buyers' พร้อมไหม"      → line_list_audiences (ต้อง READY)
3. "ซ้อมส่งดูก่อนว่ากี่คน เปลือง quota เท่าไหร่"        → line_send_message (mode: dry_run)
4. "โอเค ส่งจริงเลย"                                  → line_send_message (mode: send_now)
5. "พรุ่งนี้ดูว่ามีคนคลิกกี่คน"                         → line_get_message_stats
```

### B) สร้าง Rich Menu แล้วผูกให้เฉพาะกลุ่ม VIP

```
1. "สร้าง rich menu VIP 3 ปุ่ม รูปนี้"                → line_build_rich_menu
2. "ผูกเมนูนี้ให้ลูกค้ากลุ่ม VIP"                     → line_link_rich_menu (auto-chunk 500)
3. "เช็กว่า user VIP คนนี้เห็นเมนูถูกไหม"             → line_audit_user_menu
```

### C) รายงานประจำสัปดาห์

```
"สรุปผล OA สัปดาห์ที่แล้ว"   → line_get_oa_report (range: last-week) → ได้ markdown report
```

### D) Retargeting คนที่สนใจ

```
1. "สร้าง audience จากคนที่คลิกโปรที่ส่งไป (รอ 24 ชม.)"  → line_build_audience_from_engagement
2. "ส่งโปรรอบสองให้กลุ่มที่คลิก"                          → line_send_message (narrowcast)
```

## 5. กฎความปลอดภัย & ลิมิตที่ต้องรู้

| เรื่อง | ค่า / กฎ |
|---|---|
| 🔒 **Token เป็นความลับ** | `LINE_CHANNEL_ACCESS_TOKEN` อยู่ใน env เท่านั้น ห้ามวางในโค้ด/แชท/commit |
| 🌙 **Quiet Hours** | 22:00–08:00 (เวลาไทย) ระบบเตือน ต้อง `force` ถึงจะส่ง |
| 📊 **Quota Guardian** | ถ้าจะใช้เกิน 95% ของ quota ที่เหลือ → บล็อก ต้อง `confirm` |
| 📣 **Broadcast ต้องยืนยัน** | ส่งทุกคน (`everyone`) ต้อง `confirm` เสมอ |
| 👥 **Narrowcast ≥50 คน** | กลุ่มเป้าหมายน้อยกว่า 50 คน LINE ปฏิเสธ |
| 📦 **Multicast ≤500/ครั้ง** | เกินนั้นระบบแบ่งให้เอง (quota นับรวม) |
| ⏱️ **Reply token ~25 วินาที** | ตอบกลับช้ากว่านั้น token หมดอายุ → ระบบ fallback ไป push |
| ⏳ **Audience รอ ~10 นาที** | สร้างเสร็จต้องรอ index (IN_PROGRESS) ก่อนใช้ส่ง |
| 📝 **ข้อความ ≤5,000 ตัว** · **Flex ≤30 KB/bubble** · **carousel ≤12** | ลิมิตรูปแบบข้อความ |
| 🖼️ **รูปต้อง HTTPS ตรง** | Rich menu/รูป — ใช้ R2/S3/Cloudinary เลี่ยงลิงก์แชร์ Drive/Dropbox · หรือให้ `line_prepare_image` จัดการให้ทั้งหมด (v2.2) |
| 🔢 **Insight ขั้นต่ำ 20 คน** | กลุ่มเล็กกว่านี้ LINE คืนค่าว่าง (privacy) · insight ดีเลย์ T-1/T-2 |

## 6. แก้ปัญหาที่เจอบ่อย

**❓ "missing LINE_CHANNEL_ACCESS_TOKEN"** → ยังไม่ได้ใส่ token ใน env หรือใส่แล้วไม่ได้ restart host

**❓ LINE 401 Unauthorized** → token ผิด/หมดอายุ → ออกใหม่ที่ LINE Developers Console (เช็กก่อนด้วย `line_check_token`)

**❓ LINE 403 Forbidden** → บางฟีเจอร์ (narrowcast, follower IDs) ต้อง premium OA หรือใช้ได้เฉพาะ TH/JP/TW

**❓ narrowcast ส่งไม่ออก** → กลุ่มเป้าหมาย < 50 คน หรือ audience ยัง IN_PROGRESS (เช็ก `line_list_audiences`)

**❓ บอทไม่ตอบข้อความ** → เช็ก webhook ด้วย `line_test_webhook` ดู reason ที่ LINE คืนมา

**❓ ลูกค้าไม่เห็น rich menu** → ใช้ `line_audit_user_menu` ดูว่าผูกเมนูถูกไหม / มีเมนูหลักหรือยัง

**❓ ส่งข้อความไม่ได้ตอนกลางคืน** → ติด Quiet Hours (22:00–08:00) สั่ง "force" ถ้าจำเป็นต้องส่งจริง

## 7. อภิธานศัพท์

| คำ | ความหมาย |
|---|---|
| **Transport** | ช่องทางส่ง: reply / push / multicast / narrowcast / broadcast |
| **Reply token** | กุญแจตอบกลับลูกค้าที่เพิ่งทัก มีอายุ ~25 วินาที |
| **Push / Multicast** | ส่งหา 1 คน / หลายคน (≤500 ต่อครั้ง) |
| **Narrowcast** | ส่งตามกลุ่มเป้าหมายหรือเงื่อนไข demographic (ต้อง ≥50 คน) |
| **Broadcast** | ส่งหาเพื่อนทุกคน (ต้องยืนยัน) |
| **Audience** | กลุ่มเป้าหมายที่บันทึกไว้ใช้ส่งซ้ำ |
| **Quota Guardian** | ระบบกันส่งเกินโควต้า (บล็อกที่ 95%) |
| **Quiet Hours** | ช่วงห้ามรบกวน 22:00–08:00 (เวลาไทย) |
| **dry_run** | ซ้อมส่ง ตรวจ+ประมาณราคา โดยไม่ส่งจริง |
| **draft** | เตรียมร่างไปตั้งเวลาในหน้า LINE OA Manager |
| **Rich Menu** | เมนูปุ่มด้านล่างหน้าแชท |
| **Flex / Imagemap / Card** | รูปแบบข้อความสวยๆ: การ์ดยืดหยุ่น / รูปกดได้ / การ์ดสำเร็จรูป |
| **LIFF** | เว็บแอปที่เปิดในกรอบ LINE |
| **Multi-OA** | โหมดจัดการหลาย OA (สำหรับ agency) |
| **T-1 / T-2 lag** | ข้อมูล insight ดีเลย์ 1–2 วัน |
